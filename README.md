# Study Sprout

A standalone, responsive study site with flashcards, quizzes, and locally saved progress. It includes sample Advanced Level practice decks for Biology, Computer Science, Basic Applied Mathematics, Chemistry, Economics, Mathematics, and Physics, plus History and English vocabulary.

The questions are original practice examples, not a complete or official syllabus. Refer to the [Tanzania Institute of Education (TIE) Form V–VI curriculum](https://www.tie.go.tz/publications/curriculum-for-upper-secondary) for authoritative subject requirements.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages

1. Put the project files in a GitHub repository. Make the repository public for a free public site.
2. In the repository, open **Settings → Pages** and set the publishing source to **GitHub Actions**.
3. Push the files to the `main` branch. The workflow in `.github/workflows/pages.yml` publishes the site; its URL appears in the Actions run and the Pages settings.
