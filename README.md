# Study Sprout

A standalone, responsive study site with flashcards, quizzes, and locally saved progress.

## Subjects

Practice decks cover Tanzania Advanced Level Biology, Computer Science, Basic Applied Mathematics, Chemistry, Economics, Mathematics, and Physics. Tanzania History and English vocabulary are also included.

Questions are original practice examples, not an official or complete syllabus. Use the [Tanzania Institute of Education (TIE) Form V–VI curriculum](https://www.tie.go.tz/publications/curriculum-for-upper-secondary) as the authoritative guide.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages

The workflow at `.github/workflows/pages.yml` publishes on pushes to `main`. Enable **Settings → Pages → GitHub Actions** in the repository if needed.
